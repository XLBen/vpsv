# 素材替换

把你画的图、录的声音放进这个文件夹，**文件名或文件夹名写成素材 id**，运行游戏就会替换掉原素材。不用改代码，也不用改任何配置。

- 全部素材 id 和用途见 [素材清单](../素材清单.md)。
- 想恢复原样，删掉对应的文件或文件夹即可。
- 文件夹里可以随意建子文件夹整理，比如 `怪物/`、`音效/`。以 `.` 或 `_` 开头的文件和文件夹会被忽略，可以用来放草稿。

## 最快的上手方式：先拆出原图再改

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s res://tools/assets_tool.gd -- unpack actor.enemy.bat
```

这会生成 `assets/overrides/怪物/actor.enemy.bat/`：
- 里面是每一帧的 PNG（`walk_0.png`、`walk_1.png`……）。
- 还有一份 `说明.txt`，写明原尺寸、轴心和每个动作的帧数。

直接改这些 PNG 就行。前缀可以一次拆一类，例如 `unpack actor.enemy.*`。

## 角色、怪物、图标、特效：三种放法

| 放法 | 例子 | 适合 |
| --- | --- | --- |
| **帧文件夹**（推荐） | `actor.enemy.bat/行走_0.png`、`行走_1.png`、`待机_0.png`…… | 逐帧画的动画，Aseprite、Photoshop 导出的序列帧 |
| **单张图** | `actor.enemy.bat.png`（任意尺寸） | 先放一张静态图看效果，所有动作都用它 |
| **整张图集** | `actor.enemy.bat.png`，布局和原图一样（一行一个动作） | 已经按原格式画好的图集，可以整体放大缩小 |

### 帧文件夹的规则

- **文件名**是「动作_序号.png」。动作名可以写英文，也可以写中文：

  | 英文 | 中文 |
  | --- | --- |
  | idle | 待机 |
  | walk | 行走 |
  | hurt | 受伤 |
  | death | 死亡 |
  | attack | 攻击（首领） |

  也可以每个动作建一个子文件夹：`行走/0.png`、`行走/1.png`。
- **帧数随意**，序号从 0 开始连续即可。
- **缺少的动作会自动借用**，所以只画「行走」也能用：
  - 受伤借用待机。
  - 死亡借用受伤或待机。
  - 待机和行走互相借。
- **尺寸**可以和原图不同，同一个素材的各帧最好一样大。不一样大时，会按最大的那帧对齐，站在地上的角色脚底对齐。
- **轴心**会自动保持在原来的相对位置。站在地上的东西是脚底中间，特效是正中间。

### 尺寸

- 游戏画面是 640×360 的像素画面。角色约 16×24，小怪 16×16，首领 32×32 到 32×40，图标 16×16。
- 画得比原图大很多，在游戏里就会显得很大。这时可以加设置文件把它缩小（见下文 `scale`）。
- **图标**（`icon.*`）和**拾取物**（`pickup.*`）会自动缩回原尺寸（多为 16×16），因为它们也显示在固定大小的界面格子里。

## 可选的设置文件

和素材同名的 `.json`（例如 `actor.enemy.bat.json`），或者帧文件夹里的 `meta.json`：

```json
{"fps": 10, "scale": 0.5, "pivot": [16, 31], "clips": {"walk": {"fps": 12, "loop": true}}}
```

| 字段 | 作用 |
| --- | --- |
| `fps` | 播放帧率（默认沿用原素材） |
| `clips` | 单个动作的帧率、是否循环 |
| `scale` | 整体缩放，例如 0.5 表示缩小一半 |
| `fit` | `true` 时缩放到原素材的帧尺寸 |
| `pivot` | 轴心像素坐标 `[x, y]`，也就是角色站立的脚底位置 |
| `align` | 各帧尺寸不同时的对齐方式：`"bottom"`（脚底对齐）或 `"center"`（居中） |
| `size` | 整张图集的帧尺寸 `[宽, 高]`（布局和原图不同时才需要） |

## 其它素材

| 素材 | 放法 |
| --- | --- |
| 音效、音乐（`sfx.*`、`bgm.*`） | 同名的 `.wav`、`.ogg` 或 `.mp3`，例如 `sfx.pickup.gem.ogg` |
| 特效色带（`ramp.*`） | 同名 PNG，宽度任意、高 1 像素，从暗到亮排列 |
| 动效曲线（`motion.*`） | 同名 JSON，格式同 `assets/generated/motion/` |
| 字体 | `font.ttf`、`font.otf` 或 `font.woff2` |

## 检查有没有放对

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s res://tools/assets_tool.gd -- check
```

它会列出：
- 每个替换品的整理结果：尺寸、各动作帧数、轴心。
- 发现的问题，例如各帧尺寸不一致、图太大。
- 认不出的文件名，并提示「是不是想写 actor.enemy.bat？」。

游戏启动时也会在输出里打印「素材替换：N 个素材使用替换品」。

## 导出后的游戏也能替换

除了这个文件夹，游戏还会读取用户数据目录里的 `overrides/` 文件夹，规则完全相同，不需要重新导出：
- macOS：`~/Library/Application Support/Godot/app_userdata/vpsy/overrides/`
- Windows：`%APPDATA%\Godot\app_userdata\vpsy\overrides\`

两处都有同一个素材时，以用户数据目录里的为准。

## 和美术工作室的关系

`assets/generated/` 是 `art-studio` 自动导出的占位素材，每次导出都会被覆盖，所以不要直接改那里。替换品永远优先于导出素材，重新导出也不会影响你放在这里的文件。
